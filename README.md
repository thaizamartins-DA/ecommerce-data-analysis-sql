- Análise de Dados de E-commerce com SQL
Este projeto tem como objetivo analisar dados de um e-commerce para identificar padrões de comportamento de usuários, performance de vendas e eficiência de campanhas de marketing.
- Objetivo
Gerar insights estratégicos a partir dos dados para apoiar a tomada de decisão.
- Tecnologias
SQL
BigQuery
- Análises realizadas
Conversão de sessões em pedidos
Taxa de abertura de e-mails
Receita por país
Engajamento por dispositivo
